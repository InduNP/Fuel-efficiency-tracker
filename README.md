
# 🚗 Fuel Efficiency Tracker

A lightweight web application that allows users to track their vehicle's fuel consumption and calculate fuel efficiency. Built using vanilla HTML, CSS, and JavaScript.

---

## 🌟 Features

- Record fuel fill-up data (date, distance, fuel volume, cost)
- Calculate and display fuel efficiency (e.g., MPG or L/100km)
- View history of entries
- Responsive design for mobile and desktop
- Data persistence using Local Storage (if applicable)
